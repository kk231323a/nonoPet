# 布布桌宠

一个使用 Electron、React、TypeScript 和动态 WebP 制作的非商业同人桌宠。

## 操作

- 左键点击：摸摸头
- 双击：惊喜跳
- 按住拖动：移动桌宠，可放到屏幕任意角落
- 右键：打开动作菜单
- 系统托盘：显示、隐藏、置顶和退出

## 动作

- 常驻吸奶嘴，并自动随机切换动作
- 摸摸头与爱心反馈
- 拖拽悬空和软着陆
- 长时间待机后打瞌睡
- 委屈屈
- 卖萌
- 捏屁屁
- 桌面底部散步
- 喊老婆
- 生气气
- 双击惊喜跳

## 开发

```powershell
pnpm install
pnpm dev
```

## 构建

```powershell
pnpm build
pnpm dist:win
```

Windows 便携版输出到 `release/`。

## 说明

这个版本使用用户本人微信表情缓存中的布布素材，仅用于本地非商业桌宠。角色名称与原始 IP 权利归原作者所有，请勿将该项目直接用于商业分发。
